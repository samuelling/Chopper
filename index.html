Each year in the game is a year of your life. The game uses a rough average life expectancy as a clock, and when your years run out, it ends. Only the year is kept, on this device. Leave it blank and it assumes you are 40.
Advanced: link a Claude Code log instead
  1. Claude Code keeps a log of your sessions as .jsonl files in a hidden folder: ~/.claude/projects on Mac and Linux, C:\Users\you\.claude\projects on Windows. The picker hides folders that start with a dot. On a Mac, press Cmd Shift . in the picker to show them, or Cmd Shift G and paste the path. On Windows, paste the path into the address bar. Choose the projects folder itself (or files inside its subfolders).
  2. Press Pick log folder below (Chrome or Edge) or Claude Code log files (any browser) and choose the folder or the files. The browser asks for your permission itself. You can also do this later: Clyde's panel at the end of the first year, and Esc → "Your footprint" afterwards.
  3. The page adds up tokens per day and turns each day into a Light to Very heavy level. Only those daily totals are kept, on this device; the log itself never leaves the page. The thresholds are invented, so it is a nudge for an art piece, not a measurement. Skip it and just tell Clyde instead.
